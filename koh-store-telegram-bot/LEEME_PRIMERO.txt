🚀 INICIO RÁPIDO (3 PASOS):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  CREAR BOT EN TELEGRAM
    • Busca @BotFather en Telegram
    • Envía: /newbot
    • Sigue las instrucciones
    • Guarda el TOKEN que te da

2️⃣  OBTENER TU ID
    • Busca @userinfobot en Telegram
    • Envía: /start
    • Guarda tu ID

3️⃣  CONFIGURAR Y EJECUTAR
    • Copia .env.example a .env
    • Edita .env con tu TOKEN e ID
    • Ejecuta: npm install
    • Ejecuta: npm start
